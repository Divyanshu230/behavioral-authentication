ABOUT THE PROJECT

A biometric layer built on how you type

Traditional authentication relies on something a user knows or holds—a password, an OTP, a token—none of which prove that the person entering it is actually the enrolled user. This project, Smart Authentication System using Behavioral Biometrics and Machine Learning, addresses that gap by treating typing rhythm itself as a credential. Every login attempt is captured as a stream of keystroke timings, converted into hold-time and flight-time features, and passed through a trained classifier that outputs a behavior match score.

The system is built end-to-end on a Python and Flask backend, with SQLite handling session and user telemetry, and Scikit-learn powering the underlying model that distinguishes an enrolled user's typical rhythm from an impostor's. Authentication does not end at login: the same signal pipeline continues to sample behavior for the duration of the session, allowing the system to flag and respond to risk in real time rather than only at the point of entry.

Developed as a final-year Bachelor of Engineering major project in Electronics and Communication Engineering, the system demonstrates how lightweight behavioral signals, combined with a modest machine learning pipeline, can meaningfully strengthen conventional authentication without adding friction for the legitimate user.
